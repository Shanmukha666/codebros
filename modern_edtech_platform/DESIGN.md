## Brand & Style

This design system crafts an engaging, modern learning environment tailored for aspiring developers, early-career engineers, and technical educators. It bridges the gap between approachable consumer education and sophisticated, high-performance developer tooling. 

The aesthetic is clean, energetic, and highly functional, characterized by:
- **Approachability without frivolity**: Clean geometry, soft corners, and friendly sans-serif headlines eliminate intimidation from programming concepts while preserving technical rigor.
- **Electric Precision**: Electric indigo paired with luminous violet accents injects vitality and momentum, driving engagement during coding milestones and curriculum progression.
- **Developer-Native Utility**: Crisp boundaries, modular panelling, and high-legibility monospaced elements replicate authentic production IDE ergonomics within a welcoming interface.

## Colors

The palette establishes high-contrast hierarchy tailored for extended learning sessions and dense interactive code workspaces:

- **Primary (`#4F46E5` - Electric Indigo)**: Anchors key interactive actions, primary callouts, and navigational active states.
- **Secondary (`#7C3AED` - Vivid Violet)**: Provides depth across secondary callouts, badges, skill tracks, and premium features.
- **Tertiary (`#10B981` - Emerald)**: Governs positive reinforcement, passing unit tests, completed curriculum modules, and progress indicators.
- **Neutrals (`#0F172A`, `#1E293B`, `#334155`, `#64748B`, `#CBD5E1`, `#F1F5F9`, `#F8FAFC`, `#FFFFFF`)**: Deep slates define authoritative typography and dark-mode coding environments, while cool off-white layers construct daylight surfaces with clarity.
- **Semantic Accents**:
  - **Warning / Streaks (`#F59E0B`)**: Gamified streak counts, XP milestones, and advisory compile warnings.
  - **Destructive / Failure (`#EF4444`)**: Compiler errors, test suite assertion failures, and critical prompts.

## Typography

Typography balances character and utilitarian scanning across documentation, exercises, and dashboards:

- **Headlines (Plus Jakarta Sans)**: Used for editorial headers, hero highlights, card titles, and progress milestones. Tight tracking (-0.03em to -0.01em) lends a structured, contemporary posture.
- **Body & Controls (Inter)**: Delivers neutral clarity across instructional content, documentation, settings, and input controls.
- **Code (JetBrains Mono)**: Optimized for terminal interfaces, inline syntax definitions, test runners, and the primary coding canvas. Features explicit distinction between ambiguous glyphs (such as `0` vs `O`, `l` vs `1`).

## Layout & Spacing

The structural layout uses an 8pt baseline cadence optimized for responsive split-screen workspaces (instructional curriculum alongside an active IDE):

- **Grid Systems**:
  - **Desktop (>= 1280px)**: 12-column layout with 24px gutters and 32px canvas margins. When in split-screen IDE mode, transitions to a multi-pane layout using flex rails with 1px divider seams.
  - **Tablet (768px - 1279px)**: 8-column layout with 20px gutters and 24px margins. Workspaces stack vertically or provide drawer tabs for code editors.
  - **Mobile (< 768px)**: 4-column layout with 16px gutters and 16px margins.
- **Panels & Gaps**: Use `space-md` (16px) for interior component relationships and `space-xl` (32px) for module boundaries.

## Elevation & Depth

Visual hierarchy leverages crisp boundary outlines paired with diffused, indigo-tinted drop shadows:

- **Level 0 (Flat / Canvas)**: `#F8FAFC` base page background; `#0F172A` in code console containers.
- **Level 1 (Card / Content Surface)**: `#FFFFFF` surface accompanied by a subtle border (`1px solid #E2E8F0`) and an ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.05)`.
- **Level 2 (Interactive Floating / Active Panels)**: Elevated cards, dropdowns, and active toolbars: `0 4px 6px -1px rgba(15, 23, 42, 0.07), 0 2px 4px -2px rgba(15, 23, 42, 0.05)`.
- **Level 3 (Modals / Overlays)**: Full popovers and completion dialogs: `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.08)`.
- **Glowing Highlights**: Active editor focus rings and completed lesson accents use soft saturated indigo/violet glows: `0 0 0 3px rgba(79, 70, 229, 0.25)`.

## Shapes

The geometric identity relies on uniform rounded corners with intentional scale progression:

- **Buttons, Badges, & Form Inputs**: Set to `0.5rem` (8px, base roundedness) for a cohesive and tactile feel.
- **Standard Cards & Module Panes**: Set to `1rem` (16px, `rounded-lg`) to preserve softness on medium-sized instructional blocks.
- **App Shell Viewports & Hero Cards**: Set to `1.5rem` (24px, `rounded-xl`) for exterior framing.
- **Terminal & Editor Window Inserts**: Sharp internal pane corners (`0px` or `4px`) enclosed within a outer `0.75rem` wrapper to emulate native developer desktop tools.

## Components

### Buttons
- **Primary**: Solid Electric Indigo (`#4F46E5`) with pure white text, font weight 600, padding `0.625rem 1.25rem`, `0.5rem` radius. On hover, background shifts to `#4338CA` with subtle elevation lift.
- **Secondary / Ghost**: Neutral slate border (`1px solid #CBD5E1`), transparent background, `#1E293B` text. On hover, fills with `#F1F5F9`.
- **Accent (Run Code / Submit)**: Vibrant Emerald (`#10B981`) background, white text, subtle green halo glow on focus.

### Input Fields & Search
- Surface: `#FFFFFF` with a 1px border of `#CBD5E1`.
- Focused: Border shifts to `#4F46E5` paired with a `0 0 0 3px rgba(79, 70, 229, 0.15)` focus ring.
- Placeholder text in `#94A3B8`.

### Chips & Badges
- **Skill Pill**: Background `#EEF2FF`, text `#4F46E5`, font size `0.75rem`, weight 600, radius `9999px`, padding `0.25rem 0.75rem`.
- **Streak Counter**: Amber background tint (`#FEF3C7`), text `#D97706`, accompanied by an icon.
- **Status Indicator**: Neutral slate background with an animated pulse dot indicating runtime execution status.

### Cards & Lesson Tiles
- Built with a `#FFFFFF` surface, `1rem` radius, `1px solid #E2E8F0` border, and Level 1 elevation.
- Includes a top progress track: 4px height bar transitioning from `#7C3AED` to `#4F46E5`.

### Code Editor Panels & Tabs
- Outer workspace container in `#0F172A` with `#1E293B` tab bar header.
- Inactive tabs: `#64748B` text, transparent background.
- Active tabs: `#F8FAFC` text, background matching the code editor canvas (`#0F172A`), topped with a 2px `#4F46E5` accent line.
- Editor line numbers in `#475569`, text syntax highlighted via custom tokens with JetBrains Mono.

### Checkboxes & Progress Checkers
- Box: 18px x 18px, `0.25rem` radius, 1.5px solid `#CBD5E1`.
- Checked: `#10B981` solid background with a centered white checkmark mark indicating completed unit tests.
